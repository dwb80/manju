## 一、设计总则

### 1.1 设计方向

平台视觉融合三重参考，但不复制任何品牌：

| 参考 | 借鉴维度 |
|------|----------|
| Runway | 媒体聚焦：暗色画布、强图片/视频预览、清晰的生成状态 |
| Linear | 项目管理密度：紧凑信息、精确状态、快速扫描、低装饰噪音 |
| VoltAgent | AI工具控制台：暗色专业底、绿色强调、技术信心 |

### 1.2 产品性格

- 专业、冷静、生产就绪
- 有创意感但不装饰
- 信息密度足够承载真实工作，但不拥挤
- 展示生成图片/视频时媒体优先
- 展示剧本/分镜/资产/剪辑/审核/交付时工作流优先

### 1.3 绝对不做

- 暖色文档助手风格
- 营销页 hero 布局
- 装饰性渐变、浮动球体、光斑
- 操作页面用超大卡片
- 单一色系主导
- 假数据/占位文本出现在生产构建中

## 二、信息架构

### 2.1 导航分组（4组）

侧边栏从上到下分为 4 个语义组，替代当前"生产创作 / 资产与数据 / 运营与管控"的三组分法：

```
顶部独立项
├── 驾驶舱          /
├── 我的待办        /todos
└── 创作工作台      /studio

组一：创作入口
├── 剧本中心        /scripts
├── 分镜导演台      /storyboards
└── AI任务队列      /ai-tasks

组二：资产工厂
├── 角色工厂        /characters
├── 场景工厂        /scenes
├── 道具工厂        /props
└── 资产中心        /assets

组三：AI生产与后期
├── 视频生产线      /video-production
├── 音频中心        /audio
├── 剪辑中心        /clips
└── 模型中心        /models

组四：运营管控
├── 项目中心        /projects
├── 审核中心        /review
├── 质检中心        /quality
├── 发布准备        /publish
└── 数据中心        /data
```

### 2.2 分组理由

| 分组 | 语义 | 用户心智 |
|------|------|----------|
| 创作入口 | "我今天要创作什么" | 编剧、分镜导演、创作者的日常入口 |
| 资产工厂 | "我有哪些可复用的素材" | 美术设计师、资产管理者 |
| AI生产与后期 | "怎么用AI生成和后期处理" | 视频导演、音频/剪辑人员 |
| 运营管控 | "项目怎么推进、怎么交付" | 制片人、审核人员、发布运营 |

### 2.3 页面关系

```
创作工作台 ←→ 剧本中心 → 分镜导演台 → 角色/场景/道具工厂
     ↓              ↓          ↓              ↓
  AI生成      AI分析拆解   AI拆分镜头    AI生成图片
     ↓              ↓          ↓              ↓
  AI任务队列 ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
     ↓
  视频生产线 → 音频中心 → 剪辑中心 → 审核中心 → 发布准备
```

## 四、页面设计

### 4.1 剧本中心 `/scripts`

**定位**: 剧本列表 + AI分析 + 审核流转入口

**布局**:

```
PageHeader (标题 + 描述)
├── StatCardGrid (4列: 总数/审核中/已通过/AI覆盖率)
├── ModuleToolbar
│   ├── left: SearchInput + 状态Filter + 集数Filter
│   └── right: AI分析 + 导入剧本 + 新建剧本(Primary)
├── Tabs (剧本列表 | 模板库 | 回收站)
└── Card
    └── Table
        ├── checkbox | 标题(+字数) | 集数 | 状态Badge | 场景数 | 角色标签 | 更新时间 | 操作
        └── Pagination
```

**设计要点**:
- 标题行显示标题 + 字数摘要（`原创剧本 · 8200字`）
- 状态使用色彩 Badge：已通过(绿) / 审核中(黄) / 草稿(灰) / 已驳回(红)
- 角色用蓝色 Badge 标签行内展示
- 操作按钮默认隐藏，hover 时显示
- 导入支持拖拽区域
- AI分析按钮可批量选中后触发

**交互**:
- 点击行 → 进入剧本编辑器（独占式）
- AI分析 → 弹窗预览分析结果（角色/场景/道具提取）
- 导入 → 拖拽弹窗，支持 .txt/.docx/.fountain/.fdx

### 4.2 剧本编辑器 `/scripts/[id]`

**定位**: 独占式全屏编辑，三栏布局

**布局**:

```
独占式 (无侧边栏, 保留 GlobalTopBar)
├── 顶部工具栏 (bg-topbar)
│   ├── 标题 (inline-edit, 自动保存)
│   ├── 作者 + 状态下拉
│   └── 保存 / 历史 / 导入导出 / 评论
├── ScriptToolbar (格式化工具栏 + AI分析按钮)
└── 三栏
    ├── 左侧 (w-64): ScriptSidebar
    │   ├── 剧集/场景导航树
    │   └── 点击跳转 + 高亮
    ├── 中部: ScriptEditor (Tiptap) / OutlineView (大纲视图)
    └── 右侧: ScriptEditRightPanel (5 Tab)
        ├── 角色: AI提取的角色列表
        ├── 场景: AI提取的场景列表
        ├── 道具: AI提取的道具列表
        ├── AI: 分析/优化/扩写
        └── 评论: 选区评论
```

**设计要点**:
- 背景使用 `#0a0a0a`（比主背景更深，编辑器沉浸感）
- 保存状态实时显示（`已保存` / `保存中...` / `未保存`）
- AI分析结果可一键入库到角色/场景/道具工厂
- 版本历史使用 Modal + 预览对比
- 错误提示统一使用 `notify`，禁止 `alert()`

### 4.3 分镜导演台 `/storyboards`

**定位**: 分镜 → 镜头 父子结构，AI拆解、图生视频

**布局**:

```
PageHeader
├── PipelineFlow (生产进度条: 剧本→分镜→资产→图片→视频→审核)
├── ModuleToolbar
│   ├── left: SearchInput + 状态Filter + 集数Filter
│   └── right: AI拆分镜头 + 新增分镜(Primary)
└── 分镜行列表 (单列纵向)
    └── StoryboardRow
        ├── 选择复选框
        ├── 左侧编号块 (40x40, 圆角6px)
        ├── 右侧内容区
        │   ├── 标题 + 状态Badge + 集数Badge + 场景Badge
        │   ├── 描述 (2行截断)
        │   ├── 对白 (1行截断)
        │   └── 角色标签(蓝) + 道具标签(紫)
        ├── [展开时] 镜头列表
        │   ├── AI拆分按钮 + 添加镜头按钮
        │   └── ShotRow: 编号 + 状态 + 标题 + 时长 + 景别 + 缩略图 + 操作
        └── 操作: 编辑 / 图生视频(Primary) / 展开(N) / 删除
```

**设计要点**:
- 单列纵向时间轴，强调叙事顺序
- PipelineFlow 顶部显示，让用户知道当前在哪个阶段
- 展开状态使用 localStorage 持久化（按 projectId 隔离）
- 选中分镜后显示批量操作条（一键图生视频）
- 镜头缩略图保持原始比例（9:16竖版不拉伸）
- 操作按钮 hover 显示，但保留至少 1-2 个高频按钮默认可见

**交互**:
- 点击分镜头 → 展开/折叠镜头列表
- AI拆分 → 分析分镜内容自动生成镜头
- 图生视频 → 选中分镜或镜头后批量提交视频生成
- 镜头状态变更只来自服务端，前端不可直接修改

### 4.4 角色/场景/道具工厂 `/characters` `/scenes` `/props`

**定位**: 资产 CRUD + AI生成 + 跨项目复制 + 版本管理

**通用布局** (FactoryCRUDPage):

```
PageHeader
├── StatCardGrid (4列, 可选)
├── ModuleToolbar
│   ├── left: SearchInput + 类型Filter + 状态Filter
│   └── right: 模板 + AI生成 + 历史 + 新建(Primary)
├── Tabs (资产列表 | 回收站) [仅当配置了回收站]
└── Card
    ├── SelectAllRow (全选当前页/筛选结果)
    ├── AssetGrid (3列网格, 场景用2:1横版, 角色/道具用3:4竖版)
    │   └── AssetCard
    │       ├── 缩略图 (object-cover for thumb, object-contain for detail)
    │       ├── 状态Badge (右上角)
    │       ├── 名称 + 元信息
    │       └── 能力标签行 (三视图/一致性包/LoRA)
    ├── Pagination
    └── EmptyState (空状态)
```

**角色工厂特殊**:
- 缩略图 3:4 竖版
- 卡片显示: 名称 + 类型 + 年龄 + 引用次数
- 标签: 三视图 / 一致性包 / LoRA / 表情库 / 动作库
- AI生成: 输入角色描述 → 生成三视图

**场景工厂特殊**:
- 缩略图 16:9 横版
- 卡片显示: 名称 + 类型(室内/室外) + 时间 + 引用次数
- 标签: 环境设定 / 光照设定 / 镜头适配

**道具工厂特殊**:
- 缩略图 1:1 方形
- 卡片显示: 名称 + 引用次数 + 跨项目数
- 删除时显示引用警告

**通用能力**:
- 5秒撤销删除（toast 带撤销按钮）
- 回收站: 软删除 → 恢复 → 永久删除（二次确认）
- 批量: 全选/批量删除/批量改类型
- AI生成: AIGenerateImageDialog → 生成图片并创建实体
- 跨项目复制: CopyToProjectDialog
- 版本历史: VersionHistoryDialog

### 4.5 视频生产线 `/video-production`

**定位**: AI视频生成 + 任务队列 + 模型选择

**布局**:

```
PageHeader
```

## 五、组件设计

### 5.1 PipelineFlow 生产流水线进度条

横向展示生产阶段进度，每个阶段是一个圆形节点 + 名称。

```
●→●→○→○→○→○
剧本 分镜 资产 图片 视频 审核
```

| 状态 | 圆点样式 | 文字色 |
|------|----------|--------|
| done | 绿色实心 + 勾号 | accent |
| running | 蓝色实心 + 旋转 | info |
| pending | 灰色空心 | muted |
| failed | 红色实心 + 感叹号 | error |
| skipped | 灰色虚线 | dim |

### 5.2 StatCard 统计卡片

```
┌─────────────────┐
│ LABEL           │ ← 11px uppercase muted
│ 24              │ ← 24px 600
│ ↑ +2 本周       │ ← 11px trend
└─────────────────┘
```

- 背景: `--bg-card`
- 边框: `--border`
- 内边距: 14px 16px
- 圆角: 8px
- 支持4种trend色: up(绿)/down(红)/warning(黄)/info(蓝)

### 5.3 Badge 状态标签

| 类型 | 背景 | 文字 | 用途 |
|------|------|------|------|

## 六、交互规范

### 6.1 反馈机制

全站统一使用 `notify` 工具，禁止 `alert()` / `window.confirm()` / `console.error()` 面向用户。

| 场景 | 反馈方式 |
|------|----------|
| 操作成功 | `notify.success(msg)` toast |
| 操作失败 | `notify.error(msg)` toast |
| 删除确认 | `<ConfirmDialog>` 组件 |
| 5秒撤销 | toast 带撤销按钮 + 倒计时 |
| 长任务 | 进度条 + 状态Badge |
| 保存中 | 输入框旁 `保存中...` 文字 |

### 6.2 状态设计

所有生产对象有 6 种标准状态:

| 状态 | Badge | 色 | 下一步 |
|------|-------|-----|--------|
| Ready 已就绪 | success | 绿 | 可用于下游 |
| Incomplete 待完善 | warning | 黄 | 补充信息 |
| Processing 处理中 | info | 蓝 | 等待完成 |
| Review 审核中 | warning | 黄 | 等待审核结果 |
| Done 完成 | success | 绿 | 进入下一阶段 |
| Failed 失败 | error | 红 | 查看原因并重试 |

### 6.3 选中与批量操作

- 单击卡片/行 → 进入详情或编辑
- 复选框 → 选中（可跨页）
- 选中后顶部显示批量操作条
- 批量操作: 删除 / 改类型 / 生成视频 / 跨项目复制

### 6.4 悬停设计

- 可点击卡片/行: `bg-card-hover`
- 文字按钮: `bg-card` + `border`
- 操作按钮: `opacity-0 → group-hover:opacity-100`，但保留至少1-2个高频按钮默认可见
- 链接: `text-secondary → text-primary`

### 6.5 分页设计

所有列表/网格页面统一使用分页组件，不分页则虚拟滚动。

**分页组件结构**:

```
左: 共 X 条 · 每页 [10/20/50] 条    右: [上一页] [1] [2] [3] ... [n] [下一页]
```

**分页规则**:
- 默认每页 10 条（表格）/ 12 条（卡片网格），用户可切换 10/20/50
- 页码超过 7 页时显示省略号 `...`
- 当前页高亮 `accent-dim` 背景
- 首页禁用"上一页"，末页禁用"下一页"
- 选中可跨页保留（checkbox 状态持久化）
- 切换页码时不触发页面跳转，仅替换列表内容
- 搜索/筛选后自动回到第 1 页

**需要分页的页面**: 剧本中心、分镜导演台、角色工厂、场景工厂、道具工厂、视频生产线任务队列、音频中心（配音任务 + 音色库）、剪辑中心片段列表、AI任务队列、我的待办

### 6.6 键盘可达性

- 所有可交互元素使用 `<button>` 或 `<a>`
- 所有按钮均有文字标签，不使用纯图标按钮
- 焦点环: `outline: 3px solid #38bdf8` + `outline-offset: 2px`
- 焦点环不被颜色块掩盖
- Tab 顺序与视觉顺序一致
- Modal 使用 Radix Dialog 自动 focus trap

### 7.1 图片展示

| 场景 | 方式 |
|------|------|

- 媒体存储在本地，不依赖外部URL

## 九、实施规则

### 9.1 技术约束

- 使用现有 Tailwind 模式
- 不使用图标库，按钮和导航项使用纯文字
- 禁止引入新视觉库（除非有明确需求）
- 禁止 inline `style={}` 硬编码颜色
- 禁止 `alert()` / `window.confirm()`
- 所有 API 调用走 `lib/api-client`
- 所有 fetch 使用 `api()` 方法

### 9.2 色彩收敛

将现有3种色彩使用方式统一:

| 当前方式 | 目标 |
|----------|------|
| `bg-emerald-500/10` (Tailwind) | 保留 |
| `bg-[#202020]` (任意值) | 收敛到 CSS 变量 `--bg-card` |
| `rgba(255,255,255,0.10)` (inline) | 收敛到 `--border` |

### 9.3 完成检查

```bat
cd frontend
npm run build
```

构建通过后检查:
- [ ] 无硬编码颜色字面量
- [ ] 无 `alert()` / `window.confirm()`
- [ ] 无假数据/占位文字
- [ ] 空状态有引导文案
- [ ] 列表页有分页组件
- [ ] 无图标，按钮均为文字
