## 1. 限界上下文列表

平台划分为 10 个限界上下文，每个上下文拥有独立的聚合根、领域事件和持久化边界。音频、字幕、多轨剪辑和渲染属于后期制作；AI 任务调度只负责模型调用；发布交付接收不可变渲染制品；通知模板、偏好、投递、已读和升级属于独立通知上下文。

### 1.1 子域分类与责任

| 上下文 | 子域类型 | 核心差异化能力 | 业务负责人 |
|---|---|---|---|
| 剧本创作 | 核心域 | 从文本到可生产剧本文档及结构化分析 | 内容产品负责人 |
| 分镜导演 | 核心域 | 剧本到可生成、可审核镜头的转换 | 导演工作流负责人 |
| AI 任务调度 | 核心域 | 多模型任务编排、成本和可追溯生成 | AI 平台负责人 |
| 后期制作 | 核心域 | 多轨剪辑、音频字幕与可复现渲染 | 后期产品负责人 |
| 资产库 | 支撑域 | 角色、场景、道具、风格的一致性、权利治理和复制复用 | 资产产品负责人 |
| 审核质量 | 支撑域 | 人工审核、质检和返工闭环 | 质量负责人 |
| 发布交付 | 支撑域 | 发布预检、平台发布和发布记录 | 运营负责人 |
| 项目管控 | 支撑域 | 项目、剧集、团队、权限、代理、排产计划、编辑租约和归档 | 项目管理负责人 |
| 智能助手 | 支撑域 | 生产控制塔、跨上下文读模型、DEP、评论、建议与工作项 | 效率产品负责人 |
| 通知 | 支撑域 | 业务事件到用户通知的模板、偏好、投递、去重与升级 | 平台产品负责人 |

负责人角色必须在迭代启动时映射到具体人员；未指定负责人时不得变更该上下文的聚合或事件契约。

## 2. 上下文关系矩阵

| 上游上下文 | 下游上下文 | 协作方式 | 关系类型 |
|-----------|-----------|---------|---------|
| 项目管控 | 剧本创作 | 项目创建后允许创建剧本 | 客户/供应商 |
| 剧本创作 | 资产库 | 剧本分析产出角色/场景/道具草稿 | 客户/供应商 |
| 剧本创作 | AI任务调度 | 创作任务触发 AI 文本生成调用 | 客户/供应商（事件驱动） |
| 剧本创作 | 分镜导演 | 剧本发布后允许创建分镜板；split_shots 采纳后产出分镜建议 | 客户/供应商（事件驱动） |
| 资产库 | 分镜导演 | 提供可引用的角色/场景/道具/风格版本 | 客户/供应商（ID + 版本引用） |
| 分镜导演 | AI任务调度 | 分镜触发生成任务 | 客户/供应商 |
| AI任务调度 | 审核质量 | 生成完成触发送审 | 客户/供应商 |
| 审核质量 | 分镜导演 | 审核结果驱动分镜状态 | 客户/供应商（事件驱动） |
| 审核质量 | AI任务调度 | 审核结果驱动 Pipeline 节点 | 客户/供应商（事件驱动） |
| 审核质量 | 发布交付 | 成片终审通过后允许发布预检与排期 | 客户/供应商（事件驱动） |
| 分镜导演 | 后期制作 | 已审核分镜视频进入剪辑工程 | 客户/供应商（事件驱动） |
| AI任务调度 | 后期制作 | AI 配音结果创建音频候选 | 客户/供应商（事件驱动） |
| 后期制作 | 发布交付 | 渲染完成创建成片草稿 | 客户/供应商（事件驱动） |
| 项目管控 | 发布交付 | 项目归档前检查发布状态 | 客户/供应商 |
| 智能助手 | 全部上下文 | 跨上下文只读查询 + 建议 | 防腐层（ACL） |
| 全部业务上下文 | 智能助手 | 版本、快照、采纳、审核、渲染和发布事实更新 DEP 投影 | 发布语言（事件驱动） |
| 项目管控 | 智能助手 | 排产、代理和编辑租约事实更新控制塔/协作投影 | 发布语言（事件驱动） |
| 审核质量 | 智能助手 / 分镜导演 | 连续性问题、批注和核销更新质量工作台与镜头提示 | 发布语言（事件驱动） |
| 全部业务上下文 | 通知 | 业务事件触发接收人解析、模板渲染、渠道投递和 SLA 升级 | 发布语言（事件驱动） |

## 3. 共享内核

以下概念跨上下文共享，由 `domain/shared/` 统一定义：

| 共享概念 | 定义位置 | 消费者 |
|---------|---------|-------|
| `AggregateRoot` | `domain/shared/aggregate-root.ts` | 全部上下文 |
| `DomainEvent` | `domain/shared/domain-event.ts` | 全部上下文 |
| `DomainError` | `domain/shared/domain-error.ts` | 全部上下文 |
| `ProjectId` | 字符串类型，由项目管控上下文生成 | 全部上下文 |
| `UserId` | 字符串类型，由系统标识 | 全部上下文 |
| `ProjectRole` | 枚举类型，角色枚举（见 [01-project-management](contexts/01-project-management.md)） | 项目管控、全部上下文（权限校验） |

> **边界说明**：跨上下文持有 `id + version` 只是引用契约，不属于共享内核。共享内核仅限基础类型和事件 envelope；任何业务聚合不得通过共享内核直接暴露给其他上下文。

> **技术优化项（P3）**：`ProjectId` / `UserId` 后续可封装为强类型值对象（含格式验证），当前阶段以字符串 + 命名约定使用。
