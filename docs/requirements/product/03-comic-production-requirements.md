# 漫剧专业生产需求

> **状态**：正式产品需求基线；已回写 `02-requirements-and-acceptance.md` 并同步分镜导演、审核质量与后期制作领域契约。
> **建模原则**：先表达用户可交付能力，不提前把所有概念升级为聚合根。

## 1. 差异化目标

本产品的核心差异化不是“能调用图片和视频模型”，而是能够把剧本稳定转换为具有漫画视觉语言、角色一致性、文字表现力和有限动态的可发行制品，并支持多人审核、批量生产和返工。

一条镜头记录必须回答：

- 画面如何构图，角色和关键物位于哪里；
- 使用了哪些已发布资产版本，如何保持风格和人物一致；
- 对白、旁白和拟声词如何排版并避让主体；
- 使用哪些漫画特效和有限动态；
- 画面、文字、音频和时间轴如何同步；
- 生成来源、人工修改、审核结论和最终成片如何追溯。

## 2. 建议统一语言

| 中文术语 | 英文名 | 定义 | 初步归属 |
|---|---|---|---|
| 画面构图 | CompositionSpec | 单个 Shot 的画幅、安全区、主体位置、景深和视觉动线 | Shot 值对象 |
| 画面层 | VisualLayer | 背景、角色、道具、前景、遮罩等可排序图层 | Shot 内实体 |
| 文字叠层 | TextOverlay | 对白气泡、旁白框、标题和字幕之外的画面文字 | Shot 内实体 |
| 拟声词 | OnomatopoeiaOverlay | 具有字形、方向、强度、动画和音效关联的漫画文字 | TextOverlay 特化类型 |
| 漫画特效 | ComicEffectCue | 速度线、冲击线、集中线、闪白、震屏、色调和颗粒等效果 | Shot 内实体 |
| 有限动态 | MotionCue | 对图层执行推、拉、摇、移、缩放、视差、口型或循环动作的时间段 | Shot 内实体/后期指令 |
| 构图模板 | CompositionTemplate | 可复用的单人、双人、群像、对峙、反应等构图约束 | 分镜导演模板 |
| 画幅安全区 | SafeArea | 在目标平台裁切或 UI 遮挡后仍可安全展示主体和文字的区域 | 项目配置值对象 |
| 表现快照 | PresentationSnapshot | 送审/渲染时冻结的构图、文字、特效、动态及资产版本 | 不可变快照 |

`Panel/Page` 是否成为独立业务对象取决于 PD-001：如果首发制品以时间轴视频为主，先作为 Shot 内布局概念；如果要同时交付条漫/页漫，则需重新评审其生命周期和聚合边界。

## 3. 功能需求

### MANGA-001 项目表现规格

**用户故事**：作为制片人或分镜导演，我希望在项目级定义画幅、阅读/播放方向和视觉安全区，使所有镜头遵守统一发行规格。

**验收条件**：

- 项目必须选择目标画幅，至少支持 `9:16`、`16:9` 和自定义比例。
- 每个发布平台可提供安全区模板；模板变更不得静默修改已送审快照。
- 分镜编辑器必须展示主体安全区、文字安全区和可能被平台 UI 遮挡的区域。
- 修改项目表现规格时，系统列出受影响 Shot；已送审或已批准 Shot 必须创建新版本后修改。

### MANGA-002 图层化构图

**用户故事**：作为分镜导演，我希望用结构化画面层表达背景、角色、道具和前景的空间关系，使 AI 生成、人工编辑和有限动态共享同一构图意图。

**验收条件**：

- Shot 至少支持背景、角色、道具、前景和遮罩层；图层具有顺序、位置、缩放、旋转、透明度和可见时间段。
- 角色层可关联已发布 Character 版本、姿态、表情、朝向和视线目标。
- 场景层可关联时间、天气、光照和镜头区域。
- 系统阻止绑定已归档或未发布资产；资产更新不自动覆盖已冻结引用。
- 构图模板应用后仍可逐层修改，并记录模板 ID 与版本。

### MANGA-003 对白气泡与旁白

**用户故事**：作为编剧和分镜导演，我希望将对白与说话角色、气泡样式和时间段关联，使文字既符合漫画表达又能进入视频合成。

**验收条件**：

- 文字叠层支持 `dialogue_bubble`、`thought_bubble`、`narration_box`、`title` 四类。
- 对白气泡必须关联 Script 对白行和说话角色；旁白允许无角色。
- 支持字体、字号、字重、颜色、描边、背景、尾巴方向、位置、最大宽度、入场和退场时间。
- 编辑器检测文字越界、主体遮挡和多个气泡重叠，并允许人工确认例外。
- 剧本对白变更时生成差异提示，不静默覆盖已人工排版文字。
- 字体必须携带授权或来源信息；发布预检阻止使用未获许可字体。

### MANGA-004 拟声词管理

**用户故事**：作为分镜导演，我希望将拟声词作为可管理的视觉和声音元素，使其在画面、音效和时间轴中保持同步。

**验收条件**：

- 拟声词包含文本、语言、强度、字形样式、方向、透视、层级、位置和显示时间段。
- 可选关联 SFX AudioAsset；移动或裁剪拟声词时间段时提示是否同步音效。
- 支持从受控词库选择和自定义录入；词库记录适用语气、默认样式和推荐音效标签。
- 生成、审核和发布快照必须包含拟声词及其关联音效版本。

### MANGA-005 漫画特效

**用户故事**：作为分镜导演，我希望使用参数化漫画特效表达速度、冲击、紧张、回忆等语义，并能安全进入渲染流程。

**验收条件**：

- 首批受控特效至少包含速度线、集中线、冲击、闪白、震屏、色调覆盖、景深和颗粒。
- 特效具有类型、参数、遮罩范围、层级、开始/结束时间和强度。
- 特效参数必须通过 schema 校验；未知特效版本不得进入最终渲染。
- 光敏风险特效必须在预检中检查频率和强度，并允许项目级禁用。
- 特效模板具有版本；模板升级不回写已冻结快照。

### MANGA-006 有限动态编排

**用户故事**：作为视频导演和剪辑人员，我希望把静态图层转为可控的有限动态，使镜头在保持漫画风格的同时具备视频表现力。

**验收条件**：

- MotionCue 至少支持推、拉、摇、移、缩放、淡入淡出、视差、震动和循环动作。
- 每条 MotionCue 关联目标图层、时间范围、起止参数和缓动曲线。
- 同一属性的重叠动作必须给出确定的优先级或阻止保存。
- 预览和最终渲染使用同一规范化参数；允许降清晰度预览，但不得改变时间和构图结果。
- 口型或表情驱动必须关联 AudioAsset/对白版本，并记录模型与参数来源。

### MANGA-007 一致性检查

**用户故事**：作为美术和审核人员，我希望系统自动发现角色、服装、场景、道具和文字表现的不连续，使返工发生在最终渲染之前。

**验收条件**：

- 检查同一角色跨 Shot 的身份、服装、主色、关键特征和左右方向连续性。
- 检查场景时段、天气、光照和关键道具连续性。
- 检查对白来源、气泡说话人、拟声词—音效同步和字幕冲突。
- 自动检查生成 QCReport；每条问题可定位到 Shot、图层和时间段。
- 人工豁免必须填写原因、操作者和有效范围，并进入审计。

### MANGA-008 可复现快照与交付

**用户故事**：作为制片人和审核员，我希望任何送审或发布制品都能还原其构图、资产、文字、特效、动态、模型和音频来源。

**验收条件**：

- 送审时生成不可变 PresentationSnapshot。
- 快照包含所有资产 ID+版本、Prompt 解析结果、构图、文字、特效、MotionCue、音频、字体、模型和参数。
- 快照任一依赖发生变化时，旧审核结论不自动适用于新快照。
- 渲染结果记录输入快照哈希；相同输入重复提交必须幂等。

## 4. 事务与一致性要求

- `AddShot` 必须在同一工作单元完成 Shot 创建、Storyboard 引用追加和 Outbox 写入；任一步失败则全部回滚。
- 排序采用显式 `shotIds`/rank 与 Storyboard 乐观锁；并发冲突返回稳定错误码和最新版本。
- Shot 内图层、文字、特效和 MotionCue 随 Shot 一致保存，不单独产生跨聚合半成品。
- 资产发布/归档、剧本发布和音频发布通过事件更新可用性投影，不直接跨聚合写入。
- 已送审快照不可变；返工创建新版本并保留前序审核链。

## 5. 产品指标

- AI 分镜建议采纳率。
- 构图模板复用率。
- 文字遮挡/越界在送审前拦截率。
- 角色和场景连续性问题密度。
- 拟声词与音效自动匹配采纳率。
- 从分镜冻结到首个可审预览的时长。
- 因表现规格变更导致的返工比例。

## 6. 目标 API 与持久化

> 以下为冻结设计目标，不表示当前实现已完成。

| 能力 | 目标 API | 关键持久化 |
|---|---|---|
| 项目表现规格 | `GET/PUT /api/v1/projects/{id}/presentation-spec` | projects.presentation_spec_json / presentation_spec_version |
| Shot 构图 | `PUT /api/v1/shots/{id}/composition` | shots.composition_json 或规范化子表 |
| 画面层 | `POST/PUT/DELETE /api/v1/shots/{id}/visual-layers/{layerId?}` | shot_visual_layers（含 asset id+version、transform、time range） |
| 文字/拟声词 | `POST/PUT/DELETE /api/v1/shots/{id}/text-overlays/{overlayId?}` | shot_text_overlays（含 scriptLine、speaker、typography、SFX ref） |
| 漫画特效 | `POST/PUT/DELETE /api/v1/shots/{id}/comic-effects/{effectId?}` | shot_comic_effects（type/schemaVersion/parameters/time range） |
| 有限动态 | `POST/PUT/DELETE /api/v1/shots/{id}/motion-cues/{cueId?}` | shot_motion_cues（target/property/from/to/easing/priority） |
| 表现预检 | `POST /api/v1/shots/{id}/presentation-precheck` | 不持久化或保存可追踪 precheck report |
| 送审快照 | `POST /api/v1/shots/{id}/review-submissions` | presentation_snapshots + review targetSnapshotHash |

实现可选择 JSON 或规范化子表，但必须支持：原子保存 Shot 内结构、稳定 ID、版本差异、查询索引、迁移、快照规范化哈希和字段级验证。不得同时维护两套可写事实源。
