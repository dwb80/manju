# 商业模式、客户画像与规模假设基线

> **状态**：V1 商业验证基线。本文中的数量是产品规划与验收假设，不是公开销售承诺；调整必须记录客户证据、成本和架构影响。  
> **边界**：V1 为单组织、本地优先/私有化部署，不包含公共 SaaS 多租户、自助订阅和跨组织资产市场。

## 1. 目标客户与购买者

### 1.1 首要客户

首要客户是具备稳定内容生产需求、已有编剧/美术/后期岗位、希望用 AI 降低重复劳动的中小型漫剧工作室、内容制作公司和 MCN 内部制作团队。

参考客户画像：

- 10～50 名核心生产用户，必要时扩展到 200 名协作者；
- 同时生产 3～20 个项目，每年交付 100～1,000 集；
- 单集 1～3 分钟、20～80 个 Shot，9:16 为主要发行画幅；
- 需要私有数据、模型密钥自持、项目级权限、成本核算和审计；
- 当前痛点是资产和 Prompt 分散、角色漂移、返工不可控、成本不透明、岗位交接依赖聊天。

大型集团、多法人多租户、个人消费者和纯静态漫画团队不是 V1 首要客户。

### 1.2 购买与使用角色

| 角色 | 购买/验收关注点 |
|---|---|
| 业务负责人 | 产能、成本、交付周期、内容效果 |
| 制片负责人 | 排期、返工、预算、团队协作 |
| 创作负责人 | 可控性、质量、一致性、人工决策权 |
| IT/安全 | 部署、身份、权限、日志、备份和数据退出 |
| 财务/采购 | 授权范围、实施费、AI 用量、续费和支持边界 |

## 2. V1 商业模式

V1 采用“年度私有化软件许可 + 实施/培训 + 可选运维支持”的企业交付模式：

- 软件许可按部署组织、约定生产用户区间和模块范围报价；
- 首次实施包括安装、身份接入、存储、模型 Provider、渠道配置、权限模板和金标准项目导入；
- AI Provider 费用默认由客户自有账号直接承担；平台提供估算、预占、结算和对账，不默认承诺模型费用包干；
- 客户要求平台代采模型用量时，必须单独约定币种、加价/服务费、额度、欠费和对账规则；
- 标准支持包含版本升级和故障支持；定制模型、工作流、渠道适配器和驻场服务单独计价；
- 当前不提供匿名试用、在线自助购买或跨客户共享资产。

具体价格表属于销售配置，不写死在领域模型；但报价必须明确用户区间、环境数量、存储、支持级别、升级权和 AI 费用承担方。

## 3. 商业验证目标

首个正式版本以设计合作客户验证，不以注册量作为成功标准：

| 目标 | 首轮验证线 |
|---|---:|
| 付费设计合作组织 | ≥ 3 家 |
| 完成正式验收并进入生产的组织 | ≥ 2 家 |
| 每家客户完成的金标准/真实项目 | ≥ 1 个 |
| 从部署到首个可审 Episode | ≤ 30 天 |
| 客户关键岗位周活跃覆盖 | ≥ 70% 的已配置核心岗位 |
| 单集生产周期相对客户基线降低 | ≥ 30% |
| 单分钟成片综合生产成本降低 | ≥ 20%，且质量线不下降 |
| 首个支持周期内 P0 数据丢失/越权事件 | 0 |

若缺少客户历史基线，先运行 2～4 周观测期后冻结对照值；不得用模型标价替代综合生产成本。

## 4. 生产规模假设

### 4.1 参考工作负载

| 维度 | 典型值 | V1 设计上限/验收点 |
|---|---:|---:|
| 单组织项目总量 | 20～100 | 100 |
| 同时活跃项目 | 3～20 | 30 |
| 单项目 Episode | 12～60 | 200 |
| 单 Episode Shot | 20～80 | 200 |
| 核心生产用户 | 10～50 | 200 并发高峰、500 注册用户 |
| 图片候选/Shot | 2～8 | 16 |
| 视频候选/Shot | 1～4 | 8 |
| 单文件上传 | 常见 ≤ 500 MB | 按媒体类型和部署配置限制 |
| 在线存储 | 1～20 TB/组织 | 由部署规格和保留策略决定 |

原设计中的 100 项目、1,000 Episode、10,000 Shot、50,000 图片和 5,000 视频继续作为最小容量回归数据集，而不是商业客户数量预测。

### 4.2 性能与后台任务

- 常规交互 P95：查询 ≤ 500ms，写入 ≤ 1s；长任务必须异步。
- 正常同时在线 50 人，高峰 200 人；500 人注册规模下权限和列表查询保持可用。
- 生成并发由 Provider、预算和部署策略共同决定，不能仅按 Web 用户数推导。
- 批量生产必须支持排队、限流、取消、部分失败、恢复和人工接管；不得产生永久 `running` 任务。
- 容量不足时优先保护写入一致性、审核和发布，不以静默丢任务降级。

## 5. 客户成功与价值度量

每个客户上线前记录基线：单集周期、人工工时、AI/外包成本、一次通过率、返工轮次、发布成功率和故障恢复时长。上线后按相同口径比较。

平台价值仪表盘必须区分：

- 模型费用、存储/渲染费用和人工/外包成本；
- 因质量提升减少的返工与因 AI 失败增加的返工；
- 生成数量与最终采纳数量；
- 平台节省时间与等待 Provider/人工审核时间。

不得以“生成次数增加”作为独立商业成功指标。

## 6. 实施、支持与数据退出

标准实施必须交付部署清单、管理员培训、岗位流程培训、权限矩阵、备份恢复演练和一个金标准项目。客户验收覆盖正常生产、权限越权、Provider 故障、恢复和标准交付包。

客户终止使用时可导出版本化项目包、媒体、字幕、Prompt/参数快照、审核和权利证据；Provider 密钥和平台内部安全秘密不得导出。合同结束后的保留和销毁由客户配置及合规要求决定，并产生审计记录。

## 7. 不纳入当前承诺的商业能力

- 公共 SaaS 多租户、在线自助注册、按月自助订阅；
- 跨组织资产交易市场和公共素材社区；
- 面向个人消费者的免费增值模式；
- 对播放量、爆款率或渠道收入作保证；
- 在未取得授权时将客户素材用于公共模型训练。

这些能力只有在客户证据、隔离架构、计费和合规决策均完成后才能进入产品排期。
